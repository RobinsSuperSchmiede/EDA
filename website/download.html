One command

Install with a script

The script downloads the right archive for your system, copies both programs to a folder in your home directory and tells you what to add to your PATH.

macOS, Linux, Termux

curl -fsSL https://raw.githubusercontent.com/RobinsSuperSchmiede/EDA/main/scripts/install.sh | sh

Installs to ~/.openshell/bin. Set OPENSHELL_VERSION=v0.2.1 to pin a version.

Windows (PowerShell)

irm https://raw.githubusercontent.com/RobinsSuperSchmiede/EDA/main/scripts/install.ps1 | iex

Installs to %LOCALAPPDATA%\OpenShell\bin and adds it to your user PATH. Open a new terminal afterwards.

You are asked nothing and the script changes nothing outside those folders (and the user PATH on Windows). Read it first if you like.

Check it

Verify and prepare

Verify a download

Every release has a SHA256SUMS.txt. Compare the checksum of your file with it.

sha256sum -c SHA256SUMS.txt --ignore-missing    # macOS: shasum -a 256 -c
Get-FileHash openshell-x86_64-pc-windows-msvc.zip -Algorithm SHA256   # PowerShell

Check the installation

openshell doctor checks the config, commands, folders and ports of a project, and your toolchain, the desktop binary and the WebView.

openshell --version
openshell doctor
SystemWhat you need
WindowsWindows 10 or 11. WebView2 comes with Windows 11.
macOSNothing for the prebuilt binaries. Xcode command line tools to build from source.
LinuxWebKitGTK 4.1 for the window. To build: libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf.
For your appThe runtime of your backend language (Python, Node.js, a JDK, a C++ toolchain …), as for any project.
From source

Build it yourself

git clone https://github.com/RobinsSuperSchmiede/EDA.git
cd EDA
cargo build --release
# put target/release on your PATH:
# openshell and openshell-desktop must stay in the same folder
  • Needs a stable Rust toolchain. On Linux also the Tauri system packages.
  • Set OPENSHELL_DESKTOP if the desktop binary lives elsewhere.
  • Run openshell doctor to see what is missing.
  • Features marked “on main” on this site are available this way before the next release.
