Agents get exactly
what you allow.

Permission scopes per mode, a human in the loop for anything critical, and a record of every call.

What agents can do

  • Read state, logs and capabilities – read
  • Operate the UI – ui
  • Call your app's functions – actions
  • Restart services, edit code – development only
  • Run declared tasks – after you approve

What stays protected

  • No arbitrary shell commands, ever
  • Files only inside the project
  • Control API on 127.0.0.1 with tokens, Host and Origin checks
  • Databases closed to agents unless you open them
  • Every call in an append-only audit log

Questions people ask

Is OpenShell a framework I have to rewrite my app for?

No. Your frontend and backend stay normal projects. OpenShell reads an openshell.json and runs them – the shell is never compiled into your app, so improving the shell improves every app.

How is it different from Tauri or Electron?

OpenShell is built on Tauri 2 and adds what you would otherwise write yourself: process supervision, health checks, logs, a database, hot reload, installers and a standard interface for AI agents. You configure instead of coding a desktop shell.

Do I need a backend?

Only if you want one. A frontend can store data in the built-in SQLite database, and AI functions can be plain scripts. Pick the building blocks you need.

Which AI agents and models work with it?

Any MCP client – Claude Code, Codex, Cursor, Copilot – and anything that speaks HTTP/JSON. OpenShell never ships or requires a model; it also detects local providers like Ollama and LM Studio.

Can an agent break my computer?

Agents only get the scopes you grant per mode, critical actions need your approval, file access is limited to the project, arbitrary commands are not possible, and every call is audited.

What does it cost?

Nothing. OpenShell is open source under the MIT license.
