Control API

Every running shell exposes a local HTTP API on 127.0.0.1:<port>. Its URL and admin token are written to <project>/.openshell/runtime.json while the shell runs:

{ "pid": 648, "url": "http://127.0.0.1:52472", "token": "…", "mode": "development", "host": "desktop", "app": "Todo App", "started_at": "…", "version": "0.1.0" }

Authenticate with Authorization: Bearer <token> (WebSocket: ?token=). Requests with a foreign Host header or a non-allow-listed Origin are rejected with 403.

Endpoints#

Method & pathTokenDescription
GET /v1/health–{ ok, app, mode, host, platform, version }
GET /sdk.js, GET /bridge.js–Frontend SDK, UI bridge script
GET /v1/status (alias /v1/info)adminApp, mode, host, platform capabilities, pid, URLs, services, bridged pages, pending approvals, agent permissions, in_background, keep_alive, remote
POST /v1/services/{name}/{start|stop|restart}adminChange the desired state (returns immediately)
GET /v1/logs?service=&since=&limit=&contains=&errors_only=admin{ lines: [{ seq, ts, service, stream, text }], last_seq }
POST /v1/shutdownadminStop all services and exit
GET /v1/approvalsadmin{ pending: [{ id, agent, tool, permission, summary, args, created_at, expires_at }] }
POST /v1/approvals/{id}/{approve|deny}adminAnswer an approval request
GET /v1/audit?limit=adminRecent audit entries
GET /v1/toolsadminTools with permission, access and input_schema
POST /v1/tools/{name}adminCall a tool with the agent policy. Header X-OpenShell-Agent names the agent.
POST /mcpadminMCP Streamable HTTP (JSON-RPC, JSON responses, Mcp-Session-Id)
GET /v1/ui/bridgeapp or adminWebSocket for bridge.js
GET /v1/sdk/infoappApp info and SDK permissions
POST /v1/sdk/call/{tool}appCall a tool with the SDK policy
POST /v1/lifecycleadminApp lifecycle from the host: { "kind": "foreground" | "background" | "low_memory" }, { "kind": "power_save", "enabled": true }, { "kind": "network", "connected": true, "metered": false } → paused/resumed services and keep_alive
GET /v1/remoteadminRemote gateway: enabled, urls, mcp_url, shared token (if shared_token), tls_fingerprint, allow, exposed, devices, blocked, pairing_uri
GET /v1/remote/devicesadminPaired devices (name, paired_at, last_seen)
POST /v1/remote/devicesadminPair a device: {"name":"laptop"} → its token (only in this answer) and pairing_uri
POST /v1/remote/devices/{name}/revokeadminRevoke a device's token
POST /v1/remote/unblockadmin{"address":"192.168.1.7"} – lift a lockout
GET /v1/updateadmin{configured, update: {current, latest, available, download, page}} from package.update_url

The optional remote gateway (runtime.remote) is a separate listener with GET /v1/health, GET /v1/remote/info and POST /mcp/app only, authorised with the shared or a device token – see Remote access.

Example#

URL=$(jq -r .url .openshell/runtime.json); TOKEN=$(jq -r .token .openshell/runtime.json)
curl -s -H "Authorization: Bearer $TOKEN" $URL/v1/status
curl -s -H "Authorization: Bearer $TOKEN" -H "X-OpenShell-Agent: my-script" -H "Content-Type: application/json" \
     -d '{"service":"backend","errors_only":true}' $URL/v1/tools/logs_read
